# 🎙️ VOICE — Компьютерын Local Яриа Танигч & VoiceStudio AI

**VOICE** нь таны компьютерт 100% локал байдлаар ажилладаг, ямар ч онлайн серверээс хамааралгүй яриа таних (Speech-to-Text), дуу хоолой хувилах (VoiceStudio AI), болон **Facebook, Google хайлт, Microsoft Word, Excel, Telegram** зэрэг бүх цонхонд **F8** товчоор шууд ярьж бичих цогц систем юм.

---

## 🌟 Гол боломжууд

1. **🌐 Chrome & Edge Өргөтгөл (1 товшилтоор эсвэл F8 товчоор шууд ярьж бичих):**
   - Facebook коммент, Google хайлт, YouTube, Messenger, Gmail зэрэг дурын вэбсайт дээр курсороо тавиад л гар дээрээ **`F8`** дарах (эсвэл дэлгэцийн баруун доод буланд гарах **🎤 VOICE** товч дээр дарах) үед ярьсан үг автоматаар бичигдэнэ.
2. **💻 Windows Бүх Програмд Бичих Туслах (Microsoft Word, Excel, Notepad):**
   - Хөтчөөс гадна офлайн програмууд дээр **`F8`** (эсвэл `Ctrl + Alt`) дарж шууд ярьж бичнэ.
3. **🎙️ VoiceStudio AI — Дуу хоолой хувилах (Voice Cloning):**
   - 5–10 секундийн ярианы бичлэгээр хоолойн өнгө тембрийг хувилж шинэ хоолой үүсгэх, монгол болон олон улсын хоолойгоор текст уншуулах.
4. **🇲🇳 3 Хэлний холимог яриа танигч (MN + EN + JA Code-Switching):**
   - Монгол, Англи, Япон хэлний холимог үгсийг алдаагүй зөв ялгаж танина.
5. **✨ Зөв бичгийн дүрэм засварлагч (`spellcheck.mn`):**
   - Ярьж бичсэн текстэн дэх үгийн алдааг илрүүлж 1 даралтаар засварлана.

---

## 🚀 1. Компьютер дээрээ суулгаж ажиллуулах (GitHub-аас)

### 1-р алхам: Төслийг татаж авах
```bash
git clone https://github.com/AriukagiinTuvshoo/voice-app.git
cd voice-app
```

### 2-р алхам: Нэг даралтаар ажиллуулах
Хавтас доторх **`Start-VOICE-App.bat`** файл дээр **давхар товшиж (Double-click)** ажиллуулна.
- Энэ нь:
  1. VoiceStudio AI Серверийг (`http://127.0.0.1:8000`)
  2. VOICE Вэб програмыг (`http://localhost:3000`)
  3. Тусгай цэвэр цонхтой Desktop Аппликейшнийг автоматаар эхлүүлнэ.

---

## 🌐 2. Google Chrome Өргөтгөл суулгах (Facebook, Google-д шууд ярьж бичих)

1. Google Chrome хөтчөө нээгээд хаягийн мөрөнд **`chrome://extensions`** гэж бичиж орно.
2. Баруун дээд буланд байрлах **Developer mode (Хөгжүүлэгчийн горим)** шилжүүлэгчийг асаана.
3. Зүүн дээд талд гарах **Load unpacked (Задалсан өргөтгөл оруулах)** товчийг дарна.
4. Төслийн хавтас доторх **`chrome-extension`** хавтсыг сонгож оруулна.
5. **Ашиглах:**
   - Одоо Facebook, Google хайлт, YouTube зэрэг дурын вэбсайт дээрээ очоод:
     - **Арга 1:** Гар дээрээ **`F8`** товч дараад ярина.
     - **Арга 2:** Дэлгэцийн баруун доод буланд байрлах **`🎤 VOICE`** товч дээр товшиж ярина.
     - Ярьж дуусаад товчоо дахин дарахад текст курсор байгаа газарт автоматаар бичигдэнэ!

---

## 📝 3. Microsoft Word, Excel дээр бичих (Windows Helper)

Word, Excel, Notepad зэрэг офлайн програмууд дээр ч мөн шууд бичихийг хүсвэл:
1. Төслийн хавтас дахь **`Install-VOICE-Helper.bat`** файлыг 1 удаа ажиллуулна.
2. Энэ нь Windows асах бүрт далд ажиллахаар тохируулагдана.
3. Курсороо Word дээр тавиад **`F8`** (эсвэл `Ctrl + Alt`) дарж ярина.
4. *(Хэрэв устгах бол `Uninstall-VOICE-Helper.bat` файлыг ажиллуулна).*

## 📁 Төслийн бүтэц

```
voice-main/
├── Start-VOICE-App.bat        # 🚀 Компьютерын Local аппликейшнийг бүрэн эхлүүлэгч

├── Uninstall-VOICE-Helper.bat # 🗑️ Системийн туслах устгагч
├── chrome-extension/          # 🌐 Chrome & Edge өргөтгөлийн бүрэн эх код
│   ├── manifest.json          # Өргөтгөлийн тохиргоо (v1.2.0 Local)
│   ├── content.js             # Вэб хуудсуудад (Facebook гэх мэт) текст оруулагч
│   ├── popup.html             # Өргөтгөлийн тохиргооны цонх (F8, хэл, товчлуур)
│   └── background.js          # Далд үйлчилгээ
├── app/                       # ⚡ Next.js Local вэб интерфэйс (Port 3000)
├── tts_server.py              # 🧠 VoiceStudio & STT хөдөлгүүр (FastAPI, Port 8000)
└── components/                # UI компонентүүд
```
