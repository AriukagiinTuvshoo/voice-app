# VOICE — Multilingual Voice-to-Text & Spellcheck

Монгол болон бусад хэлний яриаг бодит цагт бичвэрт хөрвүүлэх, зөв бичгийн дүрэм автоматаар шалгах дэвшилтэт веб аппликейшн.

Энэхүү системд **Duudlaga Flow** (`https://github.com/Tsagaanbayr1/duudlaga-flow`) болон **Mongolian Spellcheck Skill** (`https://github.com/Tsagaanbayr1/mongolian-spellcheck-skill`)-ийн бүх боломжуудыг бүрэн нэгтгэн хөгжүүлсэн.

---

## 🚀 Гол онцлогууд

### 1. Chimege AI STT Интеграцчлал (Монгол яриа танилт)
- **Chimege API v1.2**:
  - `Standard STT` (`/v1.2/transcribe`): Богино ярианд маш хурдан шуурхай үр дүн.
  - `Long STT` (`/v1.2/stt-long` & `/v1.2/stt-long-transcript`): Урт яриа, лекц, хурлын аудиог найдвартай боловсруулах.
- **WAV 16kHz, 16-bit Mono Audio Encoder**: Вэб хөтөч дээрх дууны өгөгдлийг Chimege API-ийн шаардлагад нийцүүлэн 16,000Hz, 1 суваг бүхий PCM WAV болгон хөрвүүлнэ.
- **Token validation (Шалгах)**: Settings цэснээс Chimege API Token-оо 0.5s чимээгүй аудио илгээн шууд баталгаажуулах тест хэрэгсэлтэй.

### 2. Mongolian Spellcheck (spellcheck.mn интеграцчлал)
- **`$encrypt` алгоритм**: spellcheck.mn-ийн шаарддаг `n = (Σ (codePoint + 1)) mod 10000000008`, `sha256_hex(String(n))` түлхүүр үүсгэгчийг найдвартай тооцно.
- **Шууд алдаа илрүүлэлт**: Алдаатай үгсийг тодорхойлж, үг бүрийн төлөө санал болгох зөв хувилбаруудыг татаж харуулна.
- **Интерактив засах**: Алдаатай үг дээр дарахад санал болгосон үгс харагдах ба 1 дарж шууд текстийг засна.
- **"Бүгдийг засах" горим**: Санал болгосон хамгийн өндөр магадлалтай үгсээр бүх алдааг нэг дор засна.

### 3. Текст боловсруулалт ба Сул үг цэвэрлэх
- **Сул үг хасах (Remove fillers)**: Монгол хэлний ярианд түгээмэл ашиглагддаг сул үгсийг (`нөгөө`, `нөгөөх`, `ер нь`, `аан`, `тэгээд`, `хөөе`, гэх мэт) сонголтоор автоматаар цэвэрлэнэ.
- **Цэг таслал, том үсэг (Auto punctuation & Capitalization)**: Өгүүлбэрийн эхний үсгийг томруулж, зай болон цэг таслалыг стандартын дагуу цэгцэлнэ.
- **Боловсруулалтын 4 горим**:
  - `Raw`: Таньсан текстийг шууд ямар ч өөрчлөлтгүй харуулна.
  - `Standard`: Цэг таслал болон өгүүлбэрийн эхлэлийг засна.
  - `Clean`: Сул үгсийг хасаж, зөв бичгийн алдааг цэвэрлэнэ.
  - `Polished`: Догол мөр, бүтэц, найруулгыг уншихад хамгийн тааламжтай хэлбэрт оруулна.

### 4. Бичлэгийн горимууд ба Waveform Visualizer
- **Toggle Mode**: Дарж эхлүүлээд, ярьж дуусаад дахин дарж дуусгана.
- **Push-to-talk**: Товчлуур (Жишээ нь: `Space`, `Ctrl+Space`, `Alt+Space`) дээр дарж байх хугацаанд бичиж, гараа авахад шууд таньж бичнэ.
- **Waveform Control**: Микрофоноос ирж буй дууны түвшинг (RMS) бодит цагт харуулах хөдөлгөөнт дууны долгион.
- **Auto-stop**: 2.5 секунд яриагүй чимээгүй байвал бичлэгийг автоматаар зогсооно.
- **Оролтын төхөөрөмж сонгох**: Системд холбогдсон микрофонуудаас сонгох боломжтой.

### 5. Түүх (History Store) ба Экспорт
- Бүх ярианы бичлэгийг огноо, цаг, үгийн тоо, ашигласан хөдөлгүүр, үргэлжилсэн хугацаатай нь хадгална.
- Хайлтын системээр хайх.
- **Export TXT / Export JSON**: Түүхийг бүхлээр нь файл болгон татаж авах.
- **Workspace-д нээх**: Хуучин түүхээс текстээ үндсэн дэлгэцэнд нээж үргэлжлүүлэн засах болон зөв бичгийн дүрэм шалгах.

## 🛠️ Ажиллуулах заавар

```bash
# 1. Сангуудыг суулгах
npm install

# 2. Хөгжүүлэлтийн серверийг эхлүүлэх
npm run dev

# 3. Төслийг бүтээх
npm run build
```

Хөтөч дээрээ `http://localhost:3000` хаягаар нэвтрэнэ.
