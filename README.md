# VOICE — Монгол Хэлний Яриа Ба Дуу Хоолойн Систем (MMS-TTS & AI Studio)

Монгол болон бусад хэлний яриаг бодит цагт бичвэрт хөрвүүлэх, зөв бичгийн дүрэм шалгах, болон **офлайн хиймэл оюуны дуу хоолой (MMS-TTS)** үүсгэх дэвшилтэт веб ба desktop аппликейшн.
---

## 🚀 Гол онцлогууд

### 1. Офлайн Монгол TTS Студи (facebook/mms-tts-khk)
- **100% Үнэгүй, Хязгааргүй**: Гадны төлбөртэй API шаардлагагүй, бүх дуу үүсгэлтийг таны компьютер дээр шууд боловсруулна.
- **VITS Neural Architecture**: Халх монгол аялгууны байгалийн дуу хоолой.
- **Нэг товшилтоор эхлүүлэх**: `run-tts.bat` файлыг ажиллуулахад автоматаар серверийг эхлүүлнэ (`localhost:8000`).
- **Студи болон шууд уншигч**: Текстээ бичээд дуу болгон сонсох, WAV файл болгон татаж авах, түүх хадгалах боломжтой.

### 2. Mongolian Spellcheck (spellcheck.mn интеграцчлал)
- **`$encrypt` алгоритм**: spellcheck.mn-ийн шаарддаг `n = (Σ (codePoint + 1)) mod 10000000008`, `sha256_hex(String(n))` тооцоолол.
- **Шууд алдаа илрүүлэлт**: Алдаатай үгсийг тодорхойлж, үг бүрийн төлөө санал болгох зөв хувилбаруудыг харуулна.
- **Интерактив засах**: 1 дарж шууд текстийг засах эсвэл "Бүгдийг засах" товчоор нэг дор цэгцлэх.

### 3. Текст боловсруулалт ба Сул үг цэвэрлэх
- **Сул үг хасах (Remove fillers)**: Монгол хэлний ярианд түгээмэл ашиглагддаг сул үгсийг (`нөгөө`, `ер нь`, `аан`, `тэгээд`, `хөөе` гэх мэт) сонголтоор цэвэрлэнэ.
- **Цэг таслал, том үсэг**: Өгүүлбэрийн эхний үсгийг томруулж, цэг таслалыг автоматаар тохируулна.
- **Боловсруулалтын 4 горим**: `Raw`, `Standard`, `Clean`, `Polished`.

### 4. Бичлэгийн горимууд ба Waveform Visualizer
- **Toggle Mode & Push-to-talk**: Товчлуураар (`Space`, `Ctrl+Space`) болон дэлгэцийн товчоор удирдах.
- **Бодит цагийн Waveform**: Микрофоноос ирж буй дууны түвшинг (RMS) амьд долгионоор дүрслэх.
- **Auto-stop**: 2.5 секунд яриагүй чимээгүй байвал бичлэгийг автоматаар зогсооно.

### 5. Duudlaga Flow Desktop Горим (Electron)
- **FlowBar**: Дэлгэцийн аль ч хэсэгт байрлах хөвөгч капсул виджет.
- **Глобал товчлол (`Ctrl+Alt`)**: Word, браузер, чат зэрэг дурын програм дээр шууд ярьж бичих.

## 🛠️ Ажиллуулах заавар

### 1. Веб аппликейшнийг эхлүүлэх
```bash
# Сангуудыг суулгах
npm install

# Хөгжүүлэлтийн горимоор эхлүүлэх
npm run dev
```
Хөтөч дээрээ **`http://localhost:3000`** хаягаар нэвтрэнэ.

### 2. Офлайн MMS-TTS Серверийг эхлүүлэх (Python)
```bash
# Хувилбар А (Windows дээр хамгийн хялбар):
run-tts.bat файл дээр давхар дарж ажиллуулах

# Хувилбар Б (Terminal дээр гараар):
pip install -r requirements.txt
uvicorn tts_server:app --port 8000
```
*Анх удаа ажиллахад модел (~150MB) автоматаар татагдаж, цаашид интернэтгүй бүрэн офлайн ажиллана.*

### 3. Desktop Mode (Duudlaga Flow шиг)
```bash
npm run desktop
# эсвэл run-desktop.bat-ийг ажиллуулна
```
