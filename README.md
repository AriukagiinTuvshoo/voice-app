## 📥 1. Татах ба Суулгах заавар (Quick Start)

Windows Smart App Control болон антивируст блоклогдох эрсдэлгүй, 100% цэвэр нээлттэй эхийн багц.

### Алхам 1: Багц татаж авах
👉 [**VOICE-Windows-v1.2.0.zip татах (GitHub Release)**](https://github.com/AriukagiinTuvshoo/voice-app/releases/download/v1.2.0/VOICE-Windows-v1.2.0.zip) *(Хэмжээ: ~390 KB)*

### Алхам 2: Системд суулгах (1 удаа хийнэ)
1. Татсан `VOICE-Windows-v1.2.0.zip` файлыг хулганы баруун товчоор дарж **Extract All... (Бүгдийг задлах)** сонгоно.
2. Задалсан хавтас доторх **`Install-VOICE.bat`** файл дээр давхар товшиж ажиллуулна.
   - Энэ нь шаардлагатай сангуудыг таны компьютерын `%LOCALAPPDATA%\VOICE-App\.venv` тусгаарлагдсан орчинд найдвартай бэлтгэнэ.
   - Дэлгэц (Desktop) дээр **`VOICE`** нэртэй нил ягаан өнгийн товчлолыг автоматаар үүсгэнэ.

> ⚠️ **Анхаарах зүйл (Шаардлага):** Таны компьютерт **Python 3.10 буюу түүнээс дээш** хувилбар суусан байх шаардлагатай. Хэрэв суулгаагүй бол [python.org/downloads](https://www.python.org/downloads/) хуудсаар орж суулгахдаа **"Add python.exe to PATH"** болон **"tcl/tk and IDLE"** (FlowBar-т хэрэгтэй)-ийг сонгосон байх ёстой. Мөн терминал дээр `winget install Python.Python.3.12` гэж бичин 1 товшилтоор суулгаж болно.

### Алхам 3: Аппликейшнийг ажиллуулах
Суулгаж дуусмагц таны Desktop дээр үүссэн **VOICE** товчлол дээр дарахад л хангалттай:
- VOICE үндсэн интерфейс (`http://127.0.0.1:8000/dashboard`) нээгдэнэ.
- Дэлгэцийн аль ч хэсэг рүү чөлөөтэй чирч зөөж болох **`VOICE FLOW`** хөвөгч товч дэлгэцийн доод хэсэгт асна.

## 🎙️ 2. Хэрхэн ашиглах вэ? (Word, Chrome, Facebook, Чатад шууд бичих)

VOICE-ийн гол давуу тал нь **курсор байгаа газарт яриаг үг алдагдалгүй шууд шивэх** явдал юм.

```text
1. Word, Excel, Chrome, Facebook, Telegram эсвэл дурын бичих талбар дээр курсороо тавина.
2. Гар дээрээ Ctrl + Alt (эсвэл F8) товч дарна (эсвэл дэлгэц дээрх VOICE FLOW товч дээр дарна).
3. Товч улаан өнгөтэй болж "Ярьж байна..." горимд шилжихэд микрофондоо ярина.
4. Ярьж дуусмагц товч автоматаар текстийг боловсруулаад яг таны курсор байсан цэгт бичиж оруулна!
```

## 🌟 3. Гол боломжууд ба Давуу талууд

### 1. 🖥️ Фокус алдахгүй технологи (`WS_EX_NOACTIVATE`)
- Хөвөгч `VOICE FLOW` капсул дээр хулганаар дарах, зөөж шилжүүлэхэд идэвхтэй ажиллаж буй Word, Браузерын цонхны **фокус, курсор огт сарнихгүй, алдагдахгүй**.
- `⋮⋮` бариулаас чирч дэлгэцийн хүссэн байрлалдаа тавьж болно (байрлалаа санах горимтой).

### 2. 🌐 3-Хэлний бодит цагийн холимог яриа (Multilingual Code-Switching)
- **Монгол + Англи + Япон зэрэг танина:** Та өгүүлбэр дундуураа гадаад үг хольж ярихад тусгай AI толь болон олон хэлний загвар ухаалгаар ялгана.
  - Жишээ: *"Сайн уу, hi my name is ..., 私の名前は..."* гэж ярихад монгол үг криллээр, англи үг латинаар, япон үг ханз/канагаар зөв бууна.
- **Хэл сэлгэх:** Товч дээрх тэмдэг дээр дарж **`🌐 AUTO`**, **`🇲🇳 MN`**, **`🇬🇧 EN`**, **`🇯🇵 JA`** горимуудын хооронд хялбар сэлгэнэ.

### 3. 🟢 VoiceStudio AI — Ногоон бэлэн төлөв & Дуу хоолой хувилах
- Дуу үүсгэгч (TTS) болон Хоолой хувилагч систем шууд **🟢 VoiceStudio AI Бэлэн (localhost:8000)** төлөвтэй ажиллана.
- **Voice Clone:** Хүний 5–10 секундийн ярианы бичлэгээр хүний дууны өнгө, тембрийг хувилж хүссэн бичвэрээ уншуулна.
- **Студи хоолойнууд:** Есүй, Батаа, Тэмүүлэн, Ану, Ананд, Марал зэрэг студийн өндөр чанартай хоолойнууд.

### 4. ✨ Монгол хэлний зөв бичгийн дүрэм (`spellcheck.mn`)
- Ярьсан болон бичсэн текст дундах үсгийн болон дүрмийн алдааг бодит цагт засна.

### 5. 🛡️ Аюулгүй байдлын хамгаалалт (Local-Only Guard)
- Гадны вэбсайтуудаас таны локал систем рүү хандах, бичсэн текстийг нууцаар уншихаас хамгаалсан **Host + Origin + Sec-Fetch-Site** хоригтой.
- Зөвхөн таны компьютер дээрх VOICE аппликейшн өөрийн сервертэй харилцах эрхтэй.

## ⌨️ Товчлуурын хослолууд (Shortcuts)

| Товчлуур | Үйлдэл | Тайлбар |
|---|---|---|
| **`Ctrl + Alt`** | 🎙️ VOICE FLOW Шууд ярих | Компьютерын дурын цонх руу шууд бичнэ |
| **`F8`** | ⚡ Шуурхай яриа эхлүүлэх | 1 товчлуураар ярьж эхлэх / дуусгах |
| **`Space`** | 🔴 Ажлын талбарт ярих | VOICE апп дотор яриа эхлүүлэх / зогсоох |
| **`Esc`** | ✕ FlowBar нуух | Хөвөгч товчийг дэлгэцээс түр нууна |
