## 📥 1. Татах ба Суулгах заавар (Quick Start)

Windows Smart App Control болон антивируст блоклогдох эрсдэлгүй, 100% цэвэр нээлттэй эхийн багц.

### Алхам 1: Багц татаж авах
👉 [**VOICE-Windows-v1.2.1.zip татах (GitHub Releases)**](https://github.com/AriukagiinTuvshoo/voice-app/releases/download/v1.2.1/VOICE-Windows-v1.2.1.zip)

> 💡 **Smart App Control-оос сэргийлэх (Чухал зөвлөмж):**  
> Татаж авсан `VOICE-Windows-v1.2.1.zip` файл дээрээ хулганы баруун товчоор дарж **Properties (Шинж чанар)** цонхыг нээн, доод талын **Unblock (Блоклолтыг гаргах)** нүдийг чагтлаад **OK** дарна уу. Ингэснээр задлахад Windows 11-ийн Smart App Control хориг тавихгүй.
> 
> *(Эсвэл PowerShell нээгээд: `Unblock-File "$env:USERPROFILE\Downloads\VOICE-Windows-v1.2.1.zip"` гэж ажиллуулж болно).*

### Алхам 2: Системд суулгах (1 удаа хийнэ)
1. Татсан `VOICE-Windows-v1.2.1.zip` файлыг хулганы баруун товчоор дарж **Extract All... (Бүгдийг задлах)** сонгоно.
2. Задалсан хавтас доторх **`Install-VOICE.bat`** файл дээр давхар товшиж ажиллуулна.
   - Энэ нь шаардлагатай сангуудыг таны компьютерын `%LOCALAPPDATA%\VOICE-App\.venv` тусгаарлагдсан орчинд найдвартай бэлтгэнэ.
   - Дэлгэц (Desktop) дээр **`VOICE`** нэртэй нил ягаан өнгийн товчлолыг автоматаар үүсгэнэ.

> ⚠️ **Системийн шаардлага:**
> - **Python 3.10 буюу түүнээс дээш** хувилбар шаардлагатай. Хэрэв таны компьютерт суугүй бол терминал дээр `winget install Python.Python.3.12` гэж ажиллуулах эсвэл [python.org/downloads](https://www.python.org/downloads/) хуудсаар орж суулгана уу (суулгахдаа **"Add python.exe to PATH"** болон **"tcl/tk and IDLE"** сонголтуудыг заавал чагтална).
> - **Node.js шаардлагагүй:** Хэрэглэгчийн талд Node.js суусан байх шаардлагагүй, бүх график интерфэйс бэлэн static байдлаар түгээгдэнэ.

### Алхам 3: Аппликейшнийг ажиллуулах
Суулгаж дуусмагц таны Desktop дээр үүссэн **VOICE** товчлол дээр дарахад л хангалттай:
- VOICE үндсэн интерфейс (`http://127.0.0.1:8000/dashboard`) нээгдэнэ.
- Дэлгэцийн баруун доод хэсэгт хөвөгч **`VOICE FLOW`** капсул гарч ирнэ.
- Аппликейшнийг олон дахин дарж эхлүүлсэн ч ганц л үндсэн процесс ажиллах ба дахин серверийн портын зөрчил (Errno 10048) үүсэхгүй.

## 🎙️ 2. Хэрхэн ашиглах вэ? (Word, Chrome, Facebook, Чатад шууд бичих)

VOICE-ийн гол давуу тал нь **курсор байгаа газарт яриаг үг алдагдалгүй шууд шивэх** явдал юм.

```text
1. Word, Excel, Chrome, Facebook, Telegram эсвэл дурын бичих талбар дээр курсороо тавина.
2. Гар дээрээ Ctrl + Alt эсвэл F8 товч дарна (эсвэл дэлгэц дээрх VOICE FLOW товч дээр дарна).
3. Товч улаан өнгөтэй болж "Ярьж байна..." горимд шилжихэд микрофондоо ярина.
4. Ярьж дуусмагц товч автоматаар текстийг боловсруулаад яг таны курсор байсан цэгт шууд хуулж оруулна!
```

> 💡 **Анхаарах зүйлс:**
> - **Гарын байрлал (Keyboard layout):** Япон, Франц, Герман гарын байрлал дээр `Ctrl + Alt` нь `AltGr` товчлуур болж тусгай тэмдэгттэй зөрчилдөж болзошгүй тул **`F8`** товчлуурыг ашиглах нь хамгийн найдвартай. Мөн Тохиргоо (Settings) цэснээс өөрийн хүссэн товчлуурыг сонгож болно.
> - **Админ эрхтэй цонх (Administrator mode):** Windows UIPI (User Interface Privilege Isolation) хамгаалалтаас шалтгаалан админ эрхээр нээгдсэн цонх руу (жишээ нь Run as Administrator-аар нээгдсэн Notepad/CMD) бичихийн тулд VOICE-г мөн адил админаар ажиллуулах шаардлагатай.

## 🌟 3. Гол боломжууд ба Давуу талууд

### 1. 🖥️ Фокус алдахгүй технологи (`WS_EX_NOACTIVATE`)
- Хөвөгч `VOICE FLOW` капсул дээр хулганаар дарах, зөөж шилжүүлэхэд идэвхтэй ажиллаж буй Word, Браузерын цонхны **фокус, курсор огт сарнихгүй, алдагдахгүй**.
- `⋮⋮` бариулаас чирч дэлгэцийн хүссэн байрлалдаа тавьж болно (дэлгэцийн байрлалыг алдаагүй санах ба олон дэлгэц дээр зөв ажиллана).
- Хэрэв FlowBar харагдахгүй болсон эсвэл дэлгэцийн гадна үлдсэн бол Тохиргоо эсвэл цэс дээрх **"📍 Байрлал сэргээх"** товчийг дарж анхны байрлалд нь шууд авчирна.

### 2. 🌐 3-Хэлний бодит цагийн холимог яриа (Multilingual Code-Switching)
- **Монгол + Англи + Япон зэрэг танина:** Та өгүүлбэр дундуураа гадаад үг хольж ярихад тусгай AI толь болон олон хэлний загвар ухаалгаар ялгана.
  - Жишээ: *"Сайн уу, hi my name is ..., 私の名前は..."* гэж ярихад монгол үг кириллээр, англи үг латинаар, япон үг ханз/канагаар зөв бууна.
- **Хэл сэлгэх:** Товч дээрх тэмдэг дээр дарж **`🌐 AUTO`**, **`🇲🇳 MN`**, **`🇬🇧 EN`**, **`🇯🇵 JA`** горимуудын хооронд хялбар сэлгэнэ.
- **Оффлайн яриа таних (Faster-Whisper):** Интернет холболтгүй үед Тохиргоо цэснээс `Faster-Whisper (Оффлайн AI)` горимыг сонгон интернетгүйгээр яриа таних боломжтой.

### 3. 🟢 VoiceStudio AI — Ногоон бэлэн төлөв & Дуу хоолой хувилах
- Дуу үүсгэгч (TTS) болон Хоолой хувилагч систем шууд **🟢 VoiceStudio AI Бэлэн (localhost:8000)** төлөвтэй ажиллана.
- **Voice Clone:** Хүний 5–10 секундийн ярианы бичлэгээр хүний дууны өнгө, тембрийг хувилж хүссэн бичвэрээ уншуулна.
- **Студи хоолойнууд:** Есүй, Батаа, Тэмүүлэн, Ану, Ананд, Марал зэрэг студийн өндөр чанартай хоолойнууд.

### 4. ✨ Монгол хэлний зөв бичгийн дүрэм (`spellcheck.mn`)
- Ярьсан болон бичсэн текст дундах үсгийн болон дүрмийн алдааг бодит цагт засна.

### 5. 🛡️ Аюулгүй байдлын хамгаалалт (Local-Only Guard & Single-Instance)
- Гадны вэбсайтуудаас таны локал систем рүү хандах, бичсэн текстийг нууцаар уншихаас хамгаалсан **Host + Origin + Sec-Fetch-Site** хоригтой.
- Win32 Named Mutex single-instance хамгаалалттай тул дахин дахин нээхэд порт давхцах алдаа гарахгүй.

## ⌨️ Товчлуурын хослолууд (Shortcuts)

| Товчлуур | Үйлдэл | Тайлбар |
|---|---|---|
| **`F8`** | ⚡ Шуурхай яриа эхлүүлэх | **Санал болгох** (AltGr зөрчилгүй, 1 товчоор ярих) |
| **`Ctrl + Alt`** | 🎙️ VOICE FLOW Шууд ярих | Компьютерын дурын цонх руу шууд бичнэ |
| **`Space`** | 🔴 Ажлын талбарт ярих | VOICE апп дотор яриа эхлүүлэх / зогсоох |
| **`Esc`** | ✕ FlowBar нуух | Хөвөгч товчийг дэлгэцээс түр нууна |

*(Тохиргоо цэснээс F8, Ctrl+Alt, Ctrl+Shift, F9, F10 зэргээс хүссэн товчлуураа сонгох боломжтой)*
