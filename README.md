# 🎙️ VOICE — Компьютерын Local Яриа Танигч (Desktop App)

**VOICE** нь таны компьютерын дэлгэц дээр байнга байрлах **VOICE FLOW** хөвөгч товчоор дамжуулан **Facebook, Chrome, Microsoft Word, Excel, Telegram** зэрэг бүх програм руу **F8** эсвэл **Ctrl + Alt** дарж (эсвэл хулганаараа товшиж) шууд ярьж бичих систем юм.

---

## 🌟 Гол боломжууд

1. **🖥️ Дэлгэц дээр хөвөх "VOICE FLOW" товч:**
   - Таны дэлгэцийн доод буланд үргэлж бэлэн байрлана.
   - Курсороо Facebook чат, Google хайлт, эсвэл Word дээр байрлуулаад:
     - **Арга 1:** Хөвөгч товч дээр хулганаараа дарна.
     - **Арга 2:** Гар дээрээ **`Ctrl + Alt`** эсвэл **`F8`** дарна.
     - Таны ярьсан үг яг курсор байгаа газарт автоматаар бичигдэнэ!
2. **⚡ 100% Local — Интернет & Онлайн сервер шаардахгүй:**
   - Таны өөрийн компьютерт ажиллана.
3. **🎙️ VoiceStudio AI — Дуу хоолой хувилах:**
   - 5–10 секундийн ярианы бичлэгээр хүний хоолойг хувилж шинэ хоолой үүсгэх, монгол текстийг студийн чанартай уншуулах.
4. **✨ Зөв бичгийн дүрэм засварлагч (`spellcheck.mn`):**
   - Ярьж бичсэн текстэн дэх үгийн алдааг илрүүлж 1 даралтаар засварлана.

---

## 🚀 Компьютер дээрээ суулгаж ашиглах (GitHub)

### 1-р арга: GitHub Releases-аас бэлэн Апп татах (Шилдэг арга)
1. Баруун талын **[Releases](https://github.com/AriukagiinTuvshoo/voice-app/releases)** хэсгээс **`VOICE-Windows-Desktop.zip`** татаж авна.
2. Файлаа дурын хавтсанд задална (Extract).
3. **`Install-VOICE.bat`** файл дээр 1 удаа давхар товшиж ажиллуулна.
   - Энэ нь таны компьютерын дэлгэц (Desktop) дээр **"VOICE - Шууд Ярьж Бичих"** гэсэн товчлол үүсгэнэ.
4. Дэлгэц дээрх товчлол эсвэл **`Start-VOICE.bat`** дээр дарахад дэлгэцийн доод талд **VOICE FLOW** хөвөгч товч гарч ирнэ.

---

### 2-р арга: Git Clone ашиглан эх кодоор нь ажиллуулах
```bash
git clone https://github.com/AriukagiinTuvshoo/voice-app.git
cd voice-app
Start-VOICE.bat
```

---

## 🎯 Хэрхэн ашиглах вэ?

1. **`Start-VOICE.bat`** файлыг ажиллуулахад дэлгэцийн баруун доод хэсэгт дараах капсул гарч ирнэ:
   ```
   [🎙 VOICE FLOW • Энд дарж ярина уу | Товчлуур: Ctrl + Alt эсвэл F8]
   ```
2. Одоо хүссэн газраа (Facebook, Messenger, Word, Notepad, Google хайлт) курсороо байрлуулна.
3. Товч дээр дарах эсвэл гар дээрээ **`Ctrl + Alt`** (эсвэл **`F8`**) дараад ярина.
4. Ярьж дуусаад товчоо дахин дарахад ярьсан зүйл тань текстийн талбарт автоматаар бичигдэнэ!
